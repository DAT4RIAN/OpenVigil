# 前端动效实施

日期：2026-09-16。任务：按 finesse-ui 为现有前端增加动效。

## 设计范围

沿用现有工业工作台和雾灰/青绿色主题，聚焦状态变化；不新增图片或动画库。

| 场景                 | 表现与目的                                                         | 预算      |
| -------------------- | ------------------------------------------------------------------ | --------- |
| 页面进入             | 页头向上归位 6px；提示已切换工作区，正文始终保持完整对比度         | 240ms     |
| 搜索、通知、详情抽屉 | 搜索/通知从触发方向轻微展开，详情抽屉从右侧进入；建立操作层级      | 180–240ms |
| 控件反馈             | 指针悬停时导航图标位移 2px；沿用按钮按压反馈；真实进度改用缩放过渡 | 140–300ms |
| 状态和登录           | 成功图标确认、空态轻微归位；登录说明和入口相隔 60ms 归位           | 180–420ms |

- 页面动画不重挂载表单，不等待动画结束才导航，不因后台轮询重新播放。
- 业务数据、数值和错误信息保持真实，不添加数字计数或虚构进度。
- 文字在动画每一帧保持完整对比度，仅无文字遮罩允许透明度淡入。
- 关闭弹层立即移除并归还焦点，避免退出动画拖延关闭。
- 默认 CSS 始终是完整终态；减少动态效果时不创建页面动画，运行中开启该偏好会取消页面动画；CSS 过渡使用同样偏好约束。
- 使用浏览器动画 API 与 CSS，仅为透明度和位移/缩放创建新动画；不设持久的 `will-change`，不增加滚动监听或循环计时器。
- 生产身份、权限和数据链路不在本次改动范围内。
